# 03. 영상 ROI 진단 — 운전대 오탐을 제거했을 때 잃는 노면

## 작업 배경과 기존 방식의 문제

Czech + Japan 혼합 모델은 `road_sample_04`에서 운전대 엠블럼과 왼쪽 하단 부품에 D40 박스 5개를 표시했습니다. 이 박스들은 같은 클래스와 시간 간격에 따라 의심 구간 3개로 묶였습니다. 반면 같은 영상에서 검증된 노면 파손 박스는 확보되지 않았습니다. 오탐 제거와 실제 파손 검출 손실을 서로 다른 질문으로 다뤄야 했습니다. [실내 오탐의 좌표와 장면](../experiments/part5_road_roi_diagnostic.md)

## 해결 가설과 기술 선택

해당 카메라에서는 운전대가 화면 하단에 집중돼 있어, 전체 이미지에서 이미 얻은 예측에 위치 필터를 적용하면 어떤 박스가 사라지는지 바로 대조할 수 있었습니다. 전체 유지 A, 상단 60% 유지 B, 노면 사다리꼴 C를 비교했습니다. 기존 예측에 중심점 판정을 적용하고 통과한 박스로 의심 구간을 다시 계산했습니다. 입력을 자르거나 모델을 재학습하면 결과를 바꾸는 요인이 더 늘어납니다.

## 프롬프트 목적과 제약

사용자는 기존 두 모델과 동일 프레임을 사용하고 예측·원본을 보존하도록 지정했습니다. 오탐 5건의 위치, 의심 구간 변화, 실제로 보이는 노면이 잘리는지까지 검토하도록 했습니다. 이후 새 영상에서 고정 경계가 파손 후보와 어떤 위치 관계에 있는지 확인하는 작업을 추가했습니다. 이는 진단 이후의 후속 지시입니다. [ROI 요청 원문](prompts/part5_3_1_roi_diagnostic.md) · [새 영상 검토 요청 원문](prompts/part5_3_2_candidate_review.md)

## AI 수행과 사용자 판단

Codex는 두 실행의 추출 JPG 59쌍과 프레임 목록을 대조하고 A가 기존 이벤트를 재현하는지 확인했습니다. A·B·C를 같은 예측에 적용해 이미지 12장에 경계와 통과 박스를 표시했습니다. 사용자는 운전대 오탐을 진단 대상으로 지정했고, 후속 단계에서는 전·후방 영상의 노면을 직접 살펴 시간대와 박스를 기록했습니다. 당시 ROI 좌표를 정하고 노면 손실을 관찰한 근거는 실험 보고서에 남아 있습니다. [ROI 실험](../experiments/part5_road_roi_diagnostic.md) · [수동 라벨 관찰](04_manual_annotation.md)

## 검증·수정과 측정 결과

| 모델·조건 | 남은 박스 | 의심 구간 | 해석 |
| --- | ---: | ---: | --- |
| Baseline A / B / C | 각 0 | 각 0 | 후처리의 입력 예측이 비어 있었습니다. |
| 혼합 A | 5 | 3 | 다섯 박스의 중심은 영상 높이의 96.9~97.8%에 있었습니다. |
| 혼합 B / C | 각 0 | 각 0 | 운전대 오탐 5건이 모두 제외됐습니다. C는 가까운 차로 가장자리도 잘랐습니다. |

비교에 사용한 기존 추론 조건은 1920×1080 영상, 0.5초 샘플링, 입력 640, confidence 0.05, RTX 3060 Ti였습니다. 후처리 비교에서는 재추론이 0회였습니다. 다음 검토는 더 넓은 노면을 남긴 B로 좁혔습니다. 새 전·후방 영상에서도 B의 하단 경계는 648px였지만 실제 도로가 그 아래에 넓게 보였습니다. 이번 수동 D20 후보 5개 중 4개의 중심이 B 밖에 있습니다. 이는 초안의 좌표에 대한 결과입니다. ## 한계와 후속 작업

오탐을 제거한 영상은 한 클립이고, 다른 영상의 파손 후보는 사용자 승인 전입니다. 카메라 각도·경사·회전에 따라 가시 노면이 바뀌므로 B는 서비스 채택 전 비교 후보로 유지했습니다. 승인된 파손·배경과 보류 영역 처리 기준을 갖춘 뒤에야 실제 Recall과 오탐 변화를 비교할 수 있습니다.
