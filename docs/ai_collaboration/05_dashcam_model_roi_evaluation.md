# 05. 모델·ROI B 비교 — 승인 GT로 오탐 제거와 정탐 손실 평가

작업일 **2026-11-25 (KST)** · Part 5.3-3

## 문제와 가설

앞선 실험에서 고정 ROI B는 혼합 모델이 운전대에 표시한 D40 박스 5개를 제거했습니다. 새 전·후방 영상에서는 사용자가 승인한 D20 GT 5개 중 4개의 중심이 B 밖에 있습니다. 이를 단서로 같은 영상에서 두 모델의 실제 정탐과 정상 배경 오탐을 대조했습니다. GT 중심이 밖에 있어도 대응 예측의 중심은 안에 있을 수 있으므로, ROI 전후에 예측을 기준으로 다시 매칭했습니다. [ROI 진단](03_video_roi_diagnostic.md) · [발행 GT와 승인 근거](04_manual_annotation.md)

## 프롬프트 목적과 제약

**사후 요약.** 사용자는 승인 GT v1의 11장에 Czech Baseline과 Czech + Japan을 같은 CUDA 설정으로 적용하고, 저장한 confidence 0.05 예측을 `>= 0.05`, `>= 0.25`의 두 기준과 ROI 적용 전후로 비교하도록 지정했습니다. 승인 정상 배경에서만 확정 FP를 세고, 실제 TP 손실과 보류·추가 검토를 추적하도록 요청했습니다. 기존 모델, GT와 산출물의 전후 무결성 확인도 요청했습니다.

**실제 원문.** 사용자 첨부 내용을 그대로 보존했습니다. 첨부와 보관본의 SHA-256은 `4ab756622b851ff31ae58c26e8852b7a35fc218db26cbac189b9c38d8fe54453`으로 일치합니다. 발송 전 편집 이력은 미확보입니다. [Part 5.3-3 요청 원문](prompts/part5_3_3_dashcam_model_roi_evaluation.md)

## 사용자 판단과 Codex 작업

사용자는 앞 단계에서 전·후방 영상을 확인하고 원본 좌표로 라벨을 편집했습니다. 정상 배경 세 장, 전체 제외 세 장과 `rear_000120` v0002 #2를 보류로 처리하는 결정을 포함해 v3의 14장 처리를 승인했습니다. 이번 단계에서는 해당 발행본을 평가 기준으로 지정했습니다. [사용자 승인 원문](prompts/part5_3_2_publish_gt.md) · [편집과 승인 기록](04_manual_annotation.md)

## 실행 중 확인한 문제와 결과

제한 셸에서 `.venv`가 참조하는 Python 실행 파일에 접근이 거부돼, 해당 실행 파일에 접근 가능한 권한으로 검증과 CUDA 추론을 완료했습니다. 첫 비교 자료에서는 같은 위치의 박스 라벨이 가려졌습니다. 저장 예측의 SHA-256을 대조한 뒤 박스 번호와 confidence 목록을 추가한 22장을 새 경로에 생성했습니다. 이 과정의 GPU 재추론은 0회였습니다. [실행·검증 절차](../experiments/part5_dashcam_model_roi_evaluation.md#재현과-보존-검사)
