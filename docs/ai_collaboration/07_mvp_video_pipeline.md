## 구현 결정과 검증

- 과거 실행을 재현할 수 있게 CLI 기본값은 Czech Baseline 640으로 두었습니다. 새 MVP 프로필은 Python 분석 함수에 정의해 CLI와 향후 웹 작업이 같은 모델과 설정을 사용하도록 했습니다. 개별 옵션은 명시한 값만 덮어씁니다.
- 전방 69장과 후방 72장의 모델 입력을 forward 직전에 측정해 배치 1·1280×1280·FP32·CUDA 0을 확인했습니다. PNG로 평가한 5.4와 실제 JPG 경로의 차이를 기록했고, MP4 처리 시간에는 디코딩·저장 및 영상마다 수행한 모델 초기화도 포함했습니다.
- 기존 시간 통합을 적용하자 전방 D00은 34초·195박스가 한 구간이 됐습니다. 후방 D40은 4.5초 한 프레임에 좌우로 떨어진 박스가 같은 구간에 들었습니다. 대표 장면 하나로 가려지는 위치를 확인할 수 있도록 원본 번호·시각·좌표와 인접 프레임 비교를 남겼습니다. [원본 대조와 측정값](../experiments/part5_mvp_video_pipeline.md)
