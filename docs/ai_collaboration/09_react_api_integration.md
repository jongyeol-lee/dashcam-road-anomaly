## Part 6.3-1 후속 검증

- 사용자는 후방 영상 통합 검증, Playwright 자동화, Windows 종료 지연 재현과 반응형 확인을 요청했다. 모델·데이터 변경과 서비스 기능 추가를 제외하고 서버 종료 정책 변경은 제안으로 남기도록 지정했다. 이 문단은 사후 요약이다. 실제 원문은 대화 첨부에 있으며 SHA-256은 `d6650012053cefe44fe11bf4f80edfe7c4f96ece28113e24acb0a455b545271d`이다.
- Codex는 요청한 회귀와 브라우저 검증을 실행했다. Playwright 12개는 프론트엔드 빌드에서 Mock 응답과 예시 흐름을 검증했다. 실제 후방 및 추가 전방 영상은 별도 작업 저장소와 실제 GPU로 분석했다. 과거 전방 영상 증빙은 기존 기록을 재사용했다.
- 종료 지연부터 구분하기 위해 미디어 연결 상태와 작업 워커 상태를 별도로 측정했다. 짧은 대조 실험에 쓰인 합성 영상은 실제 도로 영상의 결과표에서 제외했다. 종료 로그를 숨기거나 Uvicorn의 기본 종료 정책을 바꾸는 수정은 적용하지 않았다.
- 기술 검증은 로컬 브라우저와 개발 서버에서 수행했다. 제품 코드는 기존 상태이며 자동화 테스트를 추가했다. 사용자 확인과 서비스 배포 상태는 후속 검토 항목이다. [Part 6.3-1 실험 기록](../experiments/part6_service_integration_validation.md)
