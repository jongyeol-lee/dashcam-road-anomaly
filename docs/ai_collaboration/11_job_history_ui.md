- **Codex의 설계와 구현.** 전체 이력 조회 조건을 URL에 저장하고 상세 링크 상태로 파일명과 목록 주소를 전달했다. 파일명 검색은 제출 시 요청하고 이력은 수동 새로고침 또는 재진입 시 갱신한다. 이전 조건의 요청을 중단하고, 부분 경고를 읽을 수 있는 목록과 함께 표시했다. 분석 결과와 검토 수는 API의 필드를 사용했다. [실험 보고서](../experiments/part6_job_history_ui.md)
