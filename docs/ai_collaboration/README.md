## 프롬프트 원문과 후속 지시

아래 원문 열 건은 사용자가 Codex에 보낸 내용입니다. 첨부 8건은 파일 내용을 그대로 복사하고 SHA-256을 대조했습니다. 수동 편집기 요청과 최종 발행 승인은 대화 본문에서 보존했습니다. 각 사례의 ‘프롬프트 목적과 제약’은 **사후 요약**입니다. 사용자는 이전 단계에서 GPT와 함께 관찰 의견을 검토했고 GPT의 프롬프트 작성 지원을 명시했습니다. 작성 지원은 GPT, 요청 전달과 영상 판독·수동 라벨 판단은 사용자, 저장소에서의 실행 도구는 Codex입니다. 개별 문장의 작성자는 특정하지 않습니다.

## 기록을 갱신할 때

기존 결과의 재현 근거는 실험 보고서·코드·Git 이력에 연결하고, 사람의 판단은 사용자 요청 또는 저장 메모에 연결합니다. 실험값에는 표본과 조건을 함께 적습니다. 검증을 마친 뒤에도 사용자 승인이나 서비스 적용이 남아 있으면 그 상태를 명시합니다. 원본 영상과 버전별 라벨은 프로젝트의 로컬 데이터 경로에서 관리하며, 아래 사례의 로컬 산출물 링크는 해당 파일이 있는 작업공간에서 열립니다. [프로젝트 기록 지침](../../AGENTS.md)
