## 3. 작업 A — 기존 오탐 위치 확인

우선 기존 `detections.csv`, `events.json`, `summary.json`과 추출 프레임을 확인해주세요.

다음 항목을 분석해주세요.

1. 오탐 박스 5개의 원본 프레임 번호와 타임스탬프
2. Bounding Box 좌표와 크기
3. 박스 중심점의 정규화 좌표
4. 이미지 내 운전대·대시보드 영역과의 관계
5. 오탐 발생 위치의 공통점
6. 실제 도로 노면과 차량 실내가 화면에서 어떻게 구분되는지

대표 프레임은 최소한 기존 오탐이 발생한 1.50초, 18.02초, 26.53초 부근을 확인해주세요.

정확한 시간이나 좌표는 기존 결과 파일에서 확인하며 임의로 만들지 마세요.

## 4. 작업 B — ROI 후보 설계

실제 프레임을 확인한 후 간단한 ROI 후보를 설계해주세요.

비교 조건은 다음과 같습니다.

| 조건 | 방식 |
|---|---|
| A | ROI 없이 기존 탐지 결과 사용 |
| B | 운전대·대시보드 등의 실내 영역을 제외하는 보수적 후처리 |
| C | 실제 노면으로 보이는 영역만 허용하는 ROI 후처리 |

B와 C의 경계는 실제 영상의 구도를 확인하여 설정해주세요.

처음부터 복잡한 도로 세그멘테이션 모델이나 새로운 AI 모델을 도입하지 마세요.

가능하면 프레임 크기에 대한 상대 좌표를 사용하여 ROI를 표현하고, 원본 이미지 해상도로 정확히 변환해주세요.

ROI 내부 판정의 기본 기준은 Bounding Box 중심점으로 통일해주세요. 박스가 ROI 경계에 걸치는 경우는 별도로 기록하고, 필요하다면 겹침 비율을 보조 지표로 사용해주세요.

**ROI는 추론 전 Crop이 아니라, 전체 프레임에서 생성된 예측 박스를 필터링하는 방식으로 먼저 검증합니다.**

이렇게 해야 입력 이미지 변화로 인한 모델 예측 차이와 ROI 필터 효과를 분리할 수 있습니다.

ROI를 오탐 5개만 정확히 제거하도록 임의 조정하지 말고, 도로와 차량 실내의 시각적 경계를 근거로 설계해주세요.

## 5. 작업 C — ROI 적용 전후 비교

동일한 원본 탐지 결과에 A·B·C 조건을 각각 적용해주세요.

다음 수치를 비교합니다.

- 필터 적용 전 탐지 박스 수
- 필터로 제외된 박스 수
- 필터 적용 후 남은 박스 수
- 클래스별 탐지 수
- 통합 의심 구간 수
- 기존 실내 오탐 5개 중 제외된 수
- 처리 시간(측정 가능한 경우)

필터 적용 후에는 기존 `group_detections()`를 사용하여 통합 구간을 다시 계산해주세요.

기존 Czech 모델과 혼합 모델 모두에 동일한 ROI 조건을 적용하여 결과를 기록해주세요.

각 조건에서 전체 프레임 추론 결과가 동일한지 확인하고, ROI 후처리로 인한 차이만 비교해주세요.

기존 결과를 재사용하기 어렵다면 동일한 영상·프레임·추론 설정으로 새 결과를 생성하되 기존 출력 폴더를 덮어쓰지 마세요.

### 중요한 해석 제한

이번 영상에는 검증된 파손 Ground Truth가 없습니다.

따라서 실내 오탐이 줄어들더라도 다음과 같이 해석해야 합니다.

- 실내 오탐 제거 효과: 검증 가능
- 실제 노면 파손 Recall 개선: 검증 불가능
- 정상 도로 오탐률의 일반화: 검증 불가능
- 다른 블랙박스 영상으로의 적용 가능성: 추가 검증 필요

오탐 5개를 모두 제거하더라도 모델의 파손 탐지 성능이 개선됐다고 표현하지 마세요.

## 6. 작업 D — ROI 시각 검토 자료

사용자가 ROI를 직접 확인할 수 있도록 비교 이미지를 생성해주세요.

다음 구성이 좋습니다.

- 원본 프레임
- 전체 화면의 YOLO 예측 박스
- 보수적 실내 제외 ROI
- 노면 중심 ROI
- ROI 적용 후 남은 박스

특히 실제 오탐이 발생한 프레임뿐 아니라 오탐이 없는 구간도 몇 장 포함해주세요.

각 이미지에 ROI 경계와 제외되는 영역을 구분하여 표시해주세요.

사용자가 다음 질문에 답할 수 있도록 구성해주세요.

1. 운전대와 대시보드는 적절히 제외되는가?
2. 차량 전방의 가까운 도로까지 지나치게 제외되지는 않는가?
3. 도로가 경사져 있거나 차량이 방향을 바꾸면 문제가 생길 가능성이 있는가?
4. 두 ROI 후보 중 어느 쪽이 보수적이고 안전한가?

도로 영역이 지나치게 잘리는 경우는 숨기지 말고 실패 사례로 기록해주세요.
