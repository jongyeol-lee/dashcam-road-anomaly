위 표는 GPT의 권장 의견이며 실제 사용자 판정과 저장 상태를 대신하지 않습니다.

최신 저장본에서 이미지별 버전, 검토 상태, 박스 개수, 클래스, 좌표 및 메모를 확인해주세요.

사용자가 파손 없음으로 명시적으로 판정하고 박스가 없는 이미지에 한해 정상 배경 승인 후보로 분류합니다.

이미지 전체가 판단 보류 상태라면 정상 배경에 포함하지 않습니다.

판단 보류 박스가 있는 이미지도 순수 정상 배경 이미지로 분류하지 않습니다.

검토 상태와 박스 또는 메모가 불일치하면 별도로 보고해주세요.

## 6. 작업 D — Part 5.3-3 평가 기준 점검

기존에 설계한 다음 평가 원칙을 유지합니다.

- 동일 클래스 및 IoU 0.50 이상을 기준으로 일대일 매칭
- 승인된 GT 우선 매칭
- 매칭되지 않은 예측의 면적 중 50% 이상이 판단 보류 영역과 겹치면 별도 집계
- 승인 GT에 대한 미탐은 그대로 유지
- 전체 판단 보류 및 미검토 이미지는 평가 제외
- 정상 배경은 사용자가 명시적으로 확인한 이미지에 한해 사용
- 프레임 단위 결과와 실제 파손 사례 단위 결과 구분

불확실 영역 처리 기준은 프로젝트 자체의 진단용 평가 규칙이며 표준 YOLO mAP 평가와 구분합니다.

파손 후보 이미지에 아직 표시되지 않은 다른 파손이 있을 가능성을 고려해주세요. 전체 라벨의 완전성이 확인되지 않았다면 매칭되지 않은 예측을 모두 확정 오탐으로 처리하지 말고 추가 시각 검토 대상으로 구분합니다.

현재 D40 승인 GT가 없으므로 D40 Recall이나 포트홀 탐지 성공률을 산정할 수 없습니다.

현재 자료는 소수 영상의 연속 프레임을 포함한 진단용 데이터이므로 전체 도로환경에 대한 일반화 성능을 주장하지 않습니다.

이번 작업에서는 평가 기준을 점검하고 문서화하되 실제 모델 추론 및 성능 평가는 진행하지 않습니다.
