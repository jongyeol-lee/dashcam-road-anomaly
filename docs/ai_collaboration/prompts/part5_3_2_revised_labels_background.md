### 배경 후보 판정 기준

배경 후보라는 이유만으로 정상 이미지로 확정하지 마세요.

사용자가 직접 확인한 결과에 따라 처리합니다.

- 평가 대상 파손이 보이지 않는 이미지: 파손 없음
- 명확한 파손이 발견된 이미지: Bounding Box 및 클래스 후보 작성
- 파손 여부가 불확실한 이미지: 판단 보류
- 판독이 어려운 이미지: 평가 제외 후보

박스가 없는 미검토 이미지 또는 판단 보류 이미지를 정상 배경으로 처리하지 마세요.

여기서 정상 배경이란 모든 도로 시설이 정상이라는 의미가 아니라, 사람이 확인할 수 있는 범위에서 평가 대상 클래스의 파손이 발견되지 않은 이미지를 의미합니다.

사용자가 배경 후보 8장을 검토할 수 있도록 편집기 실행 명령과 사용 방법을 안내해주세요.

## 6. 작업 D — 향후 평가를 위한 불확실 영역 처리 설계

기존 평가 코드에서는 판단 보류 영역을 별도로 처리하는 기능이 아직 없습니다.

Part 5.3-3에서 필요한 평가 기준을 다음과 같이 설계해주세요.

1. 승인된 GT와 모델 예측을 동일 클래스 및 IoU 기준으로 일대일 매칭
2. 승인된 GT를 우선 평가
3. 매칭되지 않은 모델 예측 중 판단 보류 영역과 겹치는 예측은 별도 분류
4. 판단 보류 영역에 해당하는 예측을 무조건 오탐으로 집계하지 않음
5. 이미지 전체 판단 보류 프레임은 평가 대상에서 제외
6. 검토되지 않은 배경 후보를 빈 GT 이미지로 사용하지 않음
7. 프레임 단위 탐지 결과와 실제 파손 사례 단위 결과를 구분

판단 보류 영역과의 겹침 기준, 예측 매칭 우선순위 및 경계 사례는 명확하게 문서화해주세요.

승인된 실제 파손에 대한 미탐을 불확실 영역 처리로 숨기지 않도록 설계해주세요.

기존 평가 코드를 검토하되 이번에는 실제 모델 추론이나 성능 평가를 진행하지 않습니다.

평가 기능의 본격적인 구현과 검증은 Part 5.3-3으로 구분해주세요.
