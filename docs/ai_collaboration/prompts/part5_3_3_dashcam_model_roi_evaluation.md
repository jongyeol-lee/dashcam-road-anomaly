두 모델 각각 동일한 발행 이미지 11장에 추론을 수행하고 원본 예측을 저장합니다.

ROI 적용 유무에 따라 추론을 반복하지 않고, 동일한 저장 예측 결과에 후처리를 적용합니다.

### 추론 설정

- `imgsz=640`
- `conf=0.05`
- `iou=0.7` — NMS IoU
- `rect=False`
- `max_det=300`
- CUDA 0
- 동일한 모델 실행 옵션, 정밀도, 배치 조건 및 이미지 순서 사용
- 원본 1920×1080 전체 이미지 입력
- Crop, 추가 증강 및 임의의 클래스 제외 금지
- GT 매칭 IoU: 0.50 이상

실제 적용된 배치 크기, 정밀도, 클래스별 NMS 여부 및 주요 추론 옵션을 기록합니다. 별도 변경이 필요하지 않다면 기존 영상 추론 방식과 일치시켜주세요.

CUDA를 사용할 수 없으면 조용히 CPU로 전환하지 말고 사유를 보고해주세요.

### Confidence 비교

- 주 평가: confidence 0.05 이상
- 보조 평가: confidence 0.25 이상

0.25 조건은 0.05에서 저장한 원본 예측을 점수 기준으로 필터링해 평가합니다.

별도의 0.25 추론 결과가 아니라 동일 예측 집합에 대한 후처리 비교라는 점을 기록합니다.

A~D 각각에 두 Confidence 조건을 적용하여 총 8개 평가 결과를 생성합니다.

실험 결과에 따라 유리한 Confidence나 IoU 조건만 선택하지 않습니다.

## 7. ROI B 적용 기준

기존 ROI B는 다음 정규화 좌표로 정의됩니다.

```python
((0, 0), (1, 0), (1, 0.60), (0, 0.60))
```

1920×1080 기준 화면 상단부터 y=648까지 허용합니다.

기존 `NormalizedRoi.classify()`의 예측 박스 중심점 판정과 경계 포함 기준을 유지해주세요.

- 경계 위 중심점은 허용
- ROI는 모델 예측 후처리
- 입력 이미지 Crop 금지
- 박스 좌표 변경 및 잘라내기 금지
- GT를 ROI 적용으로 제외하거나 수정하지 않음
- ROI 적용 전후 동일한 GT 5개를 분모로 사용

확정 GT 5개 중 4개의 중심점이 ROI B 바깥에 위치하지만, 이는 실제 모델 정탐 손실이 아닙니다.

모델 예측 박스를 기준으로 ROI의 실제 영향을 확인해주세요.

## 8. 평가 규칙

### 8.1 정탐 및 미탐

동일 클래스이며 IoU 0.50 이상인 GT와 예측을 일대일 매칭합니다.

기존 IoU 우선 방식과 일관되도록 높은 IoU를 우선하고, IoU가 동일한 경우 높은 Confidence, 이후 안정적으로 부여한 GT 및 예측 ID 순서로 결정해주세요.

이 규칙은 자체 진단용 매칭 규칙이며 표준 YOLO mAP 계산 방식과 구분합니다.

- 동일 클래스 정답 매칭: TP
- 매칭되지 않은 확정 GT: FN
- 하나의 GT에 여러 예측을 TP로 집계하지 않음

클래스가 다르지만 IoU 0.50 이상인 예측은 클래스 혼동 진단으로 별도 기록하되 TP로 인정하지 않습니다.

클래스 혼동이나 보류 영역 판정이 확정 GT의 FN을 숨겨서는 안 됩니다.

### 8.2 판단 보류 영역

확정 GT의 동일 클래스 정탐 매칭을 먼저 수행합니다.

이후 미매칭 예측에 대해 보류 영역 합집합과 예측 박스의 교차 면적을 계산합니다.

```text
보류 영역 포함 비율 =
area(prediction ∩ union(uncertain_regions))
/ area(prediction)
```

해당 비율이 0.50 이상이면 보류 영역 예측으로 별도 집계합니다.

보류 영역끼리 겹치는 부분을 중복 합산하지 않습니다.

보류 영역 규칙은 프로젝트 자체의 진단 기준이며 표준 객체 탐지 평가 규칙으로 표현하지 않습니다.

### 8.3 오탐 및 추가 검토

정상 배경으로 명시적으로 승인된 3장에서 발생하는 예측만 확정 배경 FP로 집계합니다.

라벨 완전성이 확인되지 않은 파손 이미지 및 부분 보류 이미지에서 발생한 나머지 미매칭 예측은 추가 시각 검토 대상으로 분류합니다.

빈 GT 목록만으로 정상 배경을 판단하지 않습니다.

보류 영역 예측, 확정 오탐, 추가 검토 예측을 별도 집계하고 중복 집계하지 않습니다.

클래스 혼동은 필요한 경우 별도 진단 속성으로 기록하되 예측 총수에 중복 합산하지 않습니다.

### 8.4 ROI 효과

각 예측에 안정적인 ID를 부여하고 ROI 적용 전후에 동일한 ID를 유지합니다.

ROI 적용 후 매칭을 다시 수행하고 다음 항목을 구분해주세요.

- ROI에 의해 제거된 기존 TP 예측
- ROI 적용 후 실제로 정탐에서 미탐으로 변경된 GT
- 다른 예측이 재매칭되어 정탐 상태를 유지한 GT
- ROI에 의해 제거된 정상 배경 FP
- 제거된 보류 영역 예측
- 제거된 추가 검토 예측
- ROI 경계와 접촉하거나 교차하는 예측

TP 박스 제거와 최종 GT 미탐 증가를 혼동하지 않습니다.
