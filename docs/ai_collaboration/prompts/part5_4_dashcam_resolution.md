| 조건 | 모델 | imgsz | ROI |

각 해상도에서 실제 입력 텐서 크기와 정밀도를 확인합니다. 해상도별 predictor 설정 및 워밍업 상태가 섞이지 않도록 주의해주세요.

1280 해상도에서 GPU 메모리 부족이 발생하면 실패 상태를 기록하고, 임의로 정밀도나 장치를 변경하여 결과를 비교하지 않습니다.

## 6. 평가 규칙

Part 5.3-3에서 구현한 기존 블랙박스 평가 규칙을 그대로 유지합니다.

- 동일 클래스 및 IoU 0.50 이상 일대일 매칭
- IoU, confidence, 안정적인 ID 순서로 동점 처리
- 확정 GT 매칭 우선
- 매칭되지 않은 GT는 FN
- 보류 영역 합집합이 예측 면적의 50% 이상이면 별도 집계
- 승인 정상 배경에서만 확정 배경 FP 집계
- 나머지 미매칭 예측은 추가 검토 대상으로 구분
- 전체 평가 제외 이미지 입력 금지
- 확정 D40 GT가 없으므로 D40 Recall은 N/A

평가 규칙이나 GT 좌표를 실험 결과에 맞춰 변경하지 않습니다.

## 7. 평가 지표 및 비교 분석

각 조건에서 다음 내용을 기록합니다.

- 전체 및 클래스별 예측 박스 수
- D20 TP / FN / Recall
- 확정 GT 5개 각각의 매칭 결과
- GT별 최대 동일 클래스 IoU 및 매칭 confidence
- 기존 640 대비 새롭게 탐지한 GT
- 기존 정탐에서 미탐으로 변경된 GT
- 정상 배경 FP 수 및 발생 이미지 수
- 보류 영역 예측 수
- 추가 검토 대상 수
- 클래스 혼동
- 전방 및 후방 영상별 결과
- 모델 추론 시간
- 전처리 및 후처리 시간
- GPU 메모리 사용량

해상도별 워밍업 이후 동일한 방식으로 시간을 측정하고 CUDA 동기화를 고려합니다.

가능한 범위에서 반복 측정으로 시간 변동을 확인하고, 평균과 중앙값을 기록합니다. GPU 메모리는 측정 범위와 allocated/reserved 구분을 명시해주세요.

단순히 픽셀 수 증가를 추론 시간 증가율로 해석하지 않습니다.

전체 Precision, F1-score, mAP는 현재 GT의 라벨 완전성과 데이터 규모를 고려하여 이번 실험에서 산출하지 않습니다.
