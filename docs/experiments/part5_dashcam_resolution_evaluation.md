## 처리 시간과 GPU 메모리

아래 시간은 워밍업 후 3회×11장 관측치의 평균 / 중앙값(ms/장)입니다. CUDA 동기화 프로파일러의 전처리·forward·NMS 및 좌표 복원 시간과, 디코딩된 이미지의 예측 호출 벽시계를 기록했습니다. 벽시계에서 PNG 디코딩, 로딩·워밍업, 파일 저장은 제외했습니다. 메모리는 워밍업 직후 피크 통계를 초기화하고 11장 추론·박스 내보내기가 끝날 때까지 측정한 PyTorch 최대 allocated / reserved입니다. Reserved에는 캐싱 할당자가 보유한 메모리가 포함됩니다. 표는 3회 중 최댓값입니다.

| 입력 | 전처리 | 모델 추론 | 후처리 | 예측 호출 전체 | 회차별 평균 추론 | 피크 allocated / reserved (MiB) |
| ---: | --- | --- | --- | --- | --- | --- |
| 640 | 1.81 / 1.75 | 12.74 / 12.04 | 1.81 / 1.68 | 16.69 / 15.71 | 12.39, 12.24, 13.57 | 70.16 / 88 |
| 960 | 2.90 / 2.93 | 12.36 / 12.02 | 1.53 / 1.74 | 17.14 / 17.20 | 12.53, 12.53, 12.02 | 94.88 / 128 |
| 1280 | 5.01 / 4.92 | 12.16 / 11.53 | 1.75 / 1.69 | 19.24 / 18.53 | 12.57, 11.80, 12.11 | 137.19 / 158 |

세 해상도 모두 OOM 없이 완료했습니다. 1280의 평균 예측 호출 시간은 640보다 2.55 ms/장 길었고, 전처리 평균이 3.20 ms/장 늘었습니다. 모델 forward 평균은 세 조건의 회차별 측정 범위가 겹칩니다. 이전 640의 11.29 ms/장과 이번 12.74 ms/장은 다른 실행에서 얻은 값입니다. 이전 실험에서는 Baseline 이후 혼합 모델을 측정했고 이번에는 혼합 모델만 3회 측정했습니다. 장치 부하 등 개별 요인의 기여도는 미확인입니다.
