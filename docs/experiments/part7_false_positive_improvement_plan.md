## 1. 배경 및 목적

실제 웹 서비스의 사용자 검토 과정에서 맨홀 뚜껑으로 보이는 정상 도로 시설물이 D40(포트홀)으로 탐지되는 사례를 발견하였다. 기존 영상 검증 과정에서도 차량 내부 구조물이 포트홀로 탐지된 사례가 있었다.

정상 도로환경의 요소를 파손으로 잘못 인식하는 사례를 수집하고 유형별로 분류하여, 학습 데이터 보강을 통해 오탐(False Positive)을 줄이는 방안을 검증한다. 실제 도로 파손에 대한 탐지 성능(특히 Recall)을 유지하는 것을 함께 목표로 한다.

## 4. 수집 및 데이터 관리

1. 웹 검토 결과에서 오탐 후보를 수집하고 원본 영상 및 대표 프레임과 연결한다.
2. 오탐 유형을 분류하고 실제 파손이 포함되었는지 원본 프레임에서 확인한다. 확신이 어려운 경우 판단 보류로 기록한다.
3. 동일 물체·연속 프레임은 그룹으로 관리한다. 박스 수, 의심 구간 수, 실제 오류 사례 수를 구분한다.
4. 유형별 빈도와 영상 환경을 조사하여 반복되는 오탐을 우선 보강한다.
5. 사용 권한, 개인정보, 라벨 품질을 확인하고 데이터 출처를 기록한다.
6. 원본 영상·주행 구간·동일 장소 등 유사 데이터가 Train/Validation/Test에 중복되지 않도록 가능한 범위에서 그룹 단위로 분할한다. 최종 독립 Test는 학습과 설정 선택에 사용하지 않는다.

### 사례 기록 권장 필드

- 영상명, 작업 UUID, 장면 ID, 원본 프레임 번호, 영상 타임스탬프
- 예측 클래스, 예측 점수, Bounding Box 좌표, 모델 버전 및 추론 설정
- 사용자 검토 상태, 별도 정답 검증 상태, 오탐 유형, 판단 근거
- 원본 프레임·대표 이미지 경로, 출처 및 이용 조건
- 원본 영상/주행 구간 그룹 ID, 데이터 분할, 학습 사용 여부

사용자 검토 상태는 후보 선별 자료로만 활용한다. 대표 이미지에 그려진 모델 Bounding Box를 그대로 정답 라벨로 사용하지 않으며, 학습에는 주석이 덧씌워지지 않은 원본 프레임을 사용한다.

## 5. 모델 개선 실험 순서

### 5.1 기준 모델 및 오류 분석

현재 Czech + Japan 혼합 YOLO11n 모델과 기존 4개 클래스(D00, D10, D20, D40)를 기준으로 삼는다. 현재 MVP 추론 설정(1280 입력 크기, confidence 0.05 등)은 실행 시 실제 코드와 대조하여 확정하고 기록한다. 기존 가중치와 평가 결과는 보존한다.

독립 주행 영상 및 검증 데이터에서 유형별 오탐과 실제 파손 미탐을 확인한다. 클래스별 confidence 기준 조정도 Validation에서 비교할 수 있으나, 점수가 낮다는 이유만으로 오탐을 확정하지 않는다.

### 5.2 1순위: Hard Negative 데이터 보강

맨홀, 그림자, 배수구 등 오탐을 유발하는 정상 도로환경 이미지의 추가 학습 효과를 검증한다. 기존 4개 클래스는 유지한다.

- 대상 파손이 없는 정상 이미지: YOLO 형식의 빈 라벨 등 기존 데이터 준비 규칙에 맞게 배경 학습에 활용한다.
- 정상 요소와 실제 파손이 함께 있는 이미지: 실제 파손은 기존 클래스에 맞춰 빠짐없이 라벨링한다.
- 기존 양성 데이터와의 구성 비율, 학습 조건, 데이터 다양성 및 라벨 품질을 기록한다.

### 5.3 2순위: 맨홀 별도 클래스 추가 (조건부)

Hard Negative 보강 후에도 맨홀 오탐이 반복되고 충분한 맨홀 라벨 데이터를 확보할 수 있을 때 검토한다. 기존 데이터의 미라벨 맨홀, 클래스 매핑, 평가 코드 및 서비스 응답 호환성을 확인한다. 정상 맨홀을 사용자 파손 의심 목록에서 제외하더라도 주변의 실제 파손을 함께 제거하지 않도록 검증한다.

## 6. 개선 전후 평가

| 평가 항목 | 확인 목적 |
| --- | --- |
| Precision, Recall, mAP50, mAP50-95 | 전체 및 클래스별 탐지 성능 비교 |
| D40 Precision/Recall, TP/FP/FN | 포트홀 오탐 감소와 실제 포트홀 미탐 증가 여부 |
| 유형별 오탐 건수 및 비율 | 동일 평가 데이터와 동일한 집계 단위에서 비교 |
| 영상 단위 오탐 의심 구간 수 | 사용자 검토 부담 변화 확인 |
| 프레임당 추론 시간 및 총 분석 시간 | 기존 영상 처리 성능 유지 여부 |

동일한 독립 평가 데이터, 평가 규칙, 추론 설정 및 장비에서 기준 모델과 개선 후보를 비교한다. 설정 자체를 변경하는 실험은 별도로 구분한다. 오탐 비율은 분모(예: 해당 정상 요소 수, 평가 프레임 수 등)를 명시하고, 표본 수가 적은 경우 일반화하지 않는다. 실제 포트홀 등 양성 정답이 있는 평가 자료도 확보한다.

모델 채택은 오탐 감소 효과와 Recall 저하 여부, 클래스별 성능 및 처리 비용을 함께 고려한다. 수치 목표 및 채택 기준은 기준 모델 평가 후 Validation 결과를 토대로 정하고, 최종 Test 결과를 본 뒤 반복적으로 조정하지 않는다.
